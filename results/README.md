# Measurement records and generated output

The JSON and JSONL files in this directory are reproducibility records produced by the benchmark harness. To the extent that their original selection and arrangement is copyrightable, the repository maintainer licenses that interest under the repository's MIT License. Individual factual measurements may not be copyrightable.

The maintainer does not claim authorship or ownership of text generated by Qwen. Published result files do not contain generated response text. They retain only cryptographic output hashes, byte counts, token counts, timings, cache evidence, and runtime statistics needed to audit the benchmark. A matching hash demonstrates parity without republishing the response.

No model weights, MTPLX source code, MLX source code, or mlx-lm source code are stored in this directory.

Published result sets:

- [`formal/`](formal/) — code-like AR/D3 interleaved repeated run and parity ablation
- [`burst-2026-08-31/`](burst-2026-08-31/) — short code-like D3 burst series
- [`content-mix-2026-09-01/`](content-mix-2026-09-01/) — Japanese, English, Simplified Chinese, and Python output-domain comparison
